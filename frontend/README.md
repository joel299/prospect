# Hermes Operation Console — Frontend

Frontend React + TypeScript da operação Prospect.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run test
npm run build
```

O alvo público previsto é `https://chat-prospect.iainfinito.com.br`. A Inbox usa a API Go e o WebSocket `/ws/v1`; áreas sem contrato de API permanecem explicitamente indisponíveis.
